# Indicativos

**Callsign es una palabra en inglés compuesta por call (llamada) y sign (signo). Es usada en la radiocomunicación para designar a uno de sus participantes.**

## Uso del Indicativo

En las comunicaciones aeronáuticas el callsign, también llamado indicativo o distintivo de llamada, se usa para saber a quien llamo o informar quién soy.
